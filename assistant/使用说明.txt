取景 · Mac 本地助手

1. 在网页“连接与设置”按引导创建 Supabase 项目、运行建库脚本。
2. 填写项目地址和公开密钥，创建账号、验证邮箱并登录。
3. 在 Mac 上安装 Python 3.11 或更新版本（https://www.python.org/downloads/macos/）。
4. 打开“启动助手.command”。首次安装依赖；没有 Ollama 时会打开官方下载页。
5. 使用和网页相同的项目地址、公开密钥、邮箱和密码连接。
6. 保持助手终端和电脑在线，上传的照片会自动分析；关闭窗口停止助手。

照片与点评保存在私人云端账号；AI 分析仅在 Mac 上的本地模型进行。
初次下载 qwen3-vl:4b-instruct 约 3.3GB，需要稳定网络；后续启动复用下载。
助手登录凭据仅保存到本机 ~/.config/photo-coach/worker.json，不保存密码。
更换账号或项目：在此文件夹打开终端，运行 .venv/bin/python worker.py --configure。

如果 macOS 提示文件无法运行：在终端进入本文件夹，运行 zsh 启动助手.command。
如果缺少 Python：先从 Python 官网安装，再打开脚本。
遇到等待分析：确认终端仍开着、电脑未休眠，网页中“电脑助手”显示“已连接”。
遇到点评失败：在网页照片详情点击“重新分析”。

仅支持 JPEG / PNG。RAW / HEIC 请先导出 JPEG。
