# 本机样片验证

2026-10-06，Apple M5 / 16GB，Ollama 0.35.1，qwen3-vl:4b-instruct。

使用公开样片测试人像、日常静物、建筑和风景，照片来源见开发记录和对应结果。最后的人像对照用同一原图和人工高斯模糊图；三个输入完全相同时，比较不能声称进步。所有结果为本地模型实际输出，网页的人工功能示例另行明确标记。

- 最终清晰人像：10.33 秒，没有强行找出技术错误。
- 最终模糊人像：16.99 秒，识别整体模糊，未编造快门、光圈或具体原因。
- 同图前后对比：验证 improved 为空，并明确说明图像一致。
- 模糊图与清晰参考图：识别清晰度差异，生成可执行的对焦练习。

这些是少量样片的初步验证；不是用户真实作品的审美或标注准确率验收。coffee / building / landscape 为较早的四类样片结果。最终对照结果使用修订后的描述式像素诊断提示。

SQL 使用 PGlite 的实际 PostgreSQL 验证队列、账号隔离与删除一致性；网页通过模拟 Supabase 响应验证完整操作流程。没有 Supabase 项目，尚未进行真实云端联调。
